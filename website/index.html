What is MI Linux?

A real installable Linux desktop, not just a theme pack.

Mann Industries Linux, short name MI Linux, is a Debian Testing / Forky-based desktop operating system project from Mann Industries. The first public release is MI Linux Forky Founder — Founder Preview.

MI Linux is being created for people who want a polished, beginner-friendly Linux desktop without giving up modern hardware support, gaming-ready performance, privacy, or control over system updates. It is not just a theme pack. The goal is a real installable operating system with a live ISO, Calamares installer, MI Linux update path, documentation, checksums, signatures, and a public build recipe.

Why it was made

MI Linux was created because many Linux choices force users to pick between extremes: very stable but older packages; very current but too risky for normal users; polished desktops that hide too much control; powerful systems that expect new users to know too much up front; and app ecosystems that push users toward unwanted defaults.

MI Linux is designed to sit in the middle: more current than Debian Stable, calmer than raw Debian Testing, polished enough for beginners, and transparent enough for advanced users. The Founder Preview is the first step toward a Mann Industries desktop OS that can be downloaded, verified, booted, installed, updated, and improved in the open.

Why MI Linux

More than a theme. Built like a real OS.

Curated Forky base

Designed around a delayed Debian Testing / Forky model: newer than Debian Stable, calmer than raw Testing.

Polished GNOME desktop

MI Linux will feel familiar from the start, with a bottom taskbar, its own visual identity, Firefox, ONLYOFFICE, Flatpak, Flathub, and GNOME Software included.

Gaming ready

Planned support for i386 multiarch, Vulkan, GameMode, MangoHud, controllers, and Proton tools without overloading the base install.

Privacy-respecting defaults

No telemetry, no required online account, no automatic usage reporting, and user-controlled bug reporting.

Real release artifacts

Bootable ISO, checksums, release notes, known issues, public source, and Cloudflare R2-hosted downloads.

Mann Industries identity

Branding, wallpaper, full-screen boot/shutdown art, welcome app, update manager, and a dedicated apt repository.

Install path

Try it live, then install with Calamares

  1. DownloadGet the ISO, checksum files, and signature from Cloudflare R2.
  2. VerifyCheck SHA256 or SHA512 before writing the image.
  3. Write USBUse Rufus, balenaEtcher, GNOME Disks, Ventoy, or the repo helper script.
  4. Boot liveStart the USB in UEFI or Legacy BIOS and try the live desktop.
  5. InstallLaunch Install MI Linux and follow the Calamares installer.
