Beginner Install Guide

The MI Linux website is not live yet. Until downloads are published here, use the GitHub repository and GitHub Releases.

Create a bootable USB from GitHub

  1. Open github.com/robertlmann02/mi-linux.
  2. Click Releases.
  3. Download the latest MI Linux ISO.
  4. Download the matching SHA256, SHA512, and GPG signature files when provided.
  5. Verify the ISO before writing it.
  6. Use Rufus, balenaEtcher, GNOME Disks, Ventoy, or the repository helper script scripts/write-usb.sh to write the ISO to USB.
  7. Boot from the USB and choose Install MI Linux from the live desktop.

Full instructions are in docs/CREATE-BOOTABLE-USB.md in the GitHub repository.

Writing an ISO erases the whole USB drive. Back up important files first.
